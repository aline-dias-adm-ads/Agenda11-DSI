# Agenda 11 - Desenvolvimento de Sistemas I

## Controle de Níveis de Água

### Objetivo
Criar uma simulação de monitoramento de um reservatório de água, exibindo mensagens coloridas conforme o nível.

### Tecnologias utilizadas
- Python
- Biblioteca Colorama

### Funcionamento
O programa utiliza duas listas: uma para armazenar as situações do reservatório e outra para definir as cores correspondentes. Uma função identifica a cor de cada nível e outra exibe a mensagem no terminal.

### Níveis do reservatório
1. Muito baixo (crítico) — vermelho.
2. Baixo — amarelo.
3. Médio — verde.
4. Alto — ciano.
5. Muito alto (alerta) — azul.

### Como executar
Instale a dependência:

`pip install -r requirements.txt`

Execute o programa:

`python main.py`
